# Electronics

This folder contains the electronic design for the prototype.

## Files

- `power-circuit.png`
  - Circuit diagram showing the connections between the Arduino UNO, L293D motor driver, DC motors, battery, and switch.

- `connection-table.png`
  - Connection tables explaining all signal and power connections between the components.

## Purpose

The circuit was designed to safely connect:
- Arduino UNO
- L293D motor driver
- DC motors
- Battery
- Switch

This design helps ensure correct wiring and safe power distribution for the prototype.
