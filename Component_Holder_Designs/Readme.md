# SolidWorks Component Holders

This folder contains the SolidWorks designs for the custom component holders used in the Arduino car project.

## Purpose

The holders were designed to attach and fix all required electronic and mechanical components securely to the car chassis.

These designs help make the prototype:

- More stable
- Better organized
- Easier to assemble
- Easier to test and modify

## Designed Components

The SolidWorks designs may include holders for:

- Arduino Uno
- Battery
- Breadboard
- Motor driver board
- IR sensors
- Ultrasonic sensors
