# Project Task Management


## Overview
This repository is used to organize and manage the project tasks in a structured and transparent way. It provides a clear breakdown of work distribution and supports ongoing tracking of progress within the team.
## File Included
- **Project_Task_Division.csv**  
  This file contains the main task table, including all project tasks, their assigned team members, and their respective details.

## Structure
The task table is organized to clearly show:
- Individual project tasks
- Assigned team members
- Task descriptions
- Progress tracking (if applicable)
