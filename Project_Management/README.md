# Project Management

## Overview

This folder contains the project planning and task management documents used to organize, track, and monitor the development of the autonomous vehicle project.

To preserve project history while supporting ongoing updates, both the original and updated task tracking versions are maintained.

## Folder Structure

### Task_Division_Old

Contains the original task tracking documents that were submitted during an earlier project milestone.

### Task_Division_and_Timeline_Updated

Contains the current project management documents.

The updated version includes:

* Excel (.xlsx) project management document
* Integrated Gantt chart timeline
* Improved task tracking and project organization
