# Electrical Design

This folder contains the electrical documentation for the prototype, including the circuit diagrams, connection tables, and component datasheets used during the design and implementation of the robot.

## Contents

### Circuit Diagrams
- `power-circuit.png`
  - Power circuit showing the electrical connections between the development board, motor driver, battery, DC motors, and power switch.

- `connection-table.jpeg`
  - Connection table describing all signal and power connections between the electronic components.

### Data Sheets
The **Data Sheets** folder contains the reference documentation for the electronic components used in the project, including:

- Development Board (ARD-R3DIP)
- Motor Driver (L298N)
- IR Sensor (KY033)
- Ultrasonic Sensor (HC-SR04)
- Conrad LiPo Battery (3200 mAh)

## Purpose

The electrical design was developed to:

- Plan the wiring of all electronic components.
- Verify the power distribution before assembly.
- Provide a clear reference for hardware implementation.
- Document the specifications of the electronic components used in the project.
