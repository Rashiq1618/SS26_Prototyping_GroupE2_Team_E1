# SysML Diagrams – Arduino Line Following and Obstacle Detection Car

This folder contains the SysML diagrams for an Arduino-based autonomous vehicle project.  
The vehicle is designed to follow a line using IR sensors and stop when an obstacle is detected using ultrasonic sensors.

## SysML Diagrams Included

This repository includes the following diagrams:

| Diagram | Purpose |
|---|---|
| Requirement Diagram | Defines the functional and non-functional requirements of the vehicle |
| Block Definition Diagram | Shows the main system blocks and their relationships |
| Internal Block Diagram | Shows how the internal components are connected |
| Use Case Diagram | Shows how the user interacts with the vehicle system |
| Sequence Diagram | Shows the runtime interaction between controller, sensors, and motors |
| Activity Diagram | Shows the vehicle control flow for line following and obstacle detection |
| Package Diagram | Organizes the SysML model into logical packages |
